## 🌟 About
 RoommateLink is a full-stack web application designed to simplify finding rental listings and compatible roommates by combining smart matching, verification, and community-driven features. Users create profiles, search for rental listings, find roommates based on shared preferences, and can speak with each other in the app.
 ## 🔑 Key Features

#### 👤 1. User Profiles

-   📄 Detailed user profiles with relevant information
    
-   📍 Users’ approximate location, biography, budget, and living preferences (e.g., smoking and pet status)
    
-   🖼️ Profile picture display
    
-   ✅ Verification badges (e.g., ID verification, email verification, phone verification)
    

----------

####  🏘️ 2. Listings and Roommate Matchmaking

-   🏠 Rental property listings by landlords or renters
    
-   👯 Roommate profiles for co-living setups
    
-   🤖 Automated suggestions based on shared preferences and needs
    

----------

####  💬 3. Communication and Interaction

-   ✉️ Messaging system for users to communicate
    
-   📌 Bookmarking feature to save favorite profiles or listings
    
-   🌟 User reviews to provide feedback on past experiences with tenants
    

----------

####  🛡️ 4. Safety and Trust

-   🪪 ID verification methods to build trust
    
-   🆔 Use of official government IDs like a driver’s license or passport
    
-   🔍 Verified badges displayed on profiles to demonstrate transparency

## 📦 Installation and setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Evan-Proulx/RoommateLink-Frontend.git
   cd RoommateLink-Frontend
2. Run `npm install`
3. create `.env`
4. Generate a [Google Maps api key](https://developers.google.com/maps)
5. Add root url and Google Maps api key to `.env`
```
 VITE_ROOT_URL=http://127.0.0.1:8000
 VITE_GOOGLE_MAPS_API_KEY=
```
6. Run `npm run dev` to run the app
